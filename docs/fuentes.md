# Documentación oficial consultada

- [Requisitos de SQL Server 2022](https://learn.microsoft.com/en-us/sql/sql-server/install/hardware-and-software-requirements-for-installing-sql-server-2022?view=sql-server-ver16): el motor Windows requiere x64.
- [Instalación de SQL Server en Linux](https://learn.microsoft.com/en-us/sql/linux/install-upgrade/setup?view=sql-server-ver16): las imágenes de contenedor se admiten en hosts Intel/AMD x86-64; la emulación ARM no está soportada.
- [Modos de renderizado de Blazor .NET 8](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/render-modes?view=aspnetcore-8.0): configuración de interactividad WebAssembly global.
- [Instalación de .NET en Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows): SDK compatible con Windows ARM64 y distribución binaria.
- [Descargas de .NET 8](https://dotnet.microsoft.com/en-us/download/dotnet/8.0): SDK y runtime de la versión solicitada.
